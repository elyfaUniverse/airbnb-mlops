# Airbnb MLOps: чтение данных из S3

Учебный проект по ML/DLOps. На первом этапе читаем подготовленную таблицу Inside Airbnb из S3-совместимого хранилища и используем локальную копию при ошибке доступа или сети.

## Структура проекта

```text
airbnb-mlops/
├── 01_read_data.ipynb  # Чтение CSV из S3 и локальной копии
├── requirements.txt    # Зависимости для первого задания
├── .env.example       # Пример настроек без настоящих ключей
├── .env               # Локальные настройки и ключи; не хранится в Git
├── .venv/             # Локальное виртуальное окружение; не хранится в Git
├── data/              # Локальная копия CSV; не хранится в Git
├── secretkeys.py      # Исходный локальный файл ключей; не хранится в Git
├── .gitignore         # Исключения для Git
└── README.md
```

Другие файлы и папки проекта — заготовки для следующих этапов; их функциональность пока не реализована.

## Источник данных

Используется подготовленный преподавателем CSV из Inside Airbnb. В примере заданы S3-совместимое хранилище Yandex Object Storage, endpoint `https://storage.yandexcloud.net` и регион `ru-central1`. Bucket — `mlops26-course-bucket`, key — `prepared/listings.csv`. Для доступа нужны действующие ключи с правом чтения объекта.

Локальная копия должна находиться в `data/listings.csv` и содержать тот же снимок данных, что и S3. После успешного первого чтения ноутбук создаёт её, если файла ещё нет. Существующая копия автоматически не перезаписывается.

## Окружение

Для проекта настроено виртуальное окружение `.venv` на Python 3.12. Если на другом компьютере его ещё нет, создайте его из папки проекта в PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Для ноутбука в VS Code выберите ядро **Python (airbnb-mlops)** или интерпретатор `.venv\Scripts\python.exe`. При необходимости зарегистрируйте ядро:

```powershell
python -m ipykernel install --user --name airbnb-mlops --display-name "Python (airbnb-mlops)"
```

Чтобы открыть Jupyter в браузере, дополнительно установите браузерный интерфейс:

```powershell
python -m pip install notebook
python -m notebook
```

Если для первого задания передаются строго три файла и `requirements.txt` отсутствует, установите библиотеки напрямую:

```powershell
python -m pip install boto3 pandas python-dotenv ipykernel
```

## Настройки S3 и ключи

Создайте локальный `.env` на основе шаблона:

```powershell
Copy-Item .env.example .env
```

Заполните в `.env` следующие переменные:

```dotenv
AWS_ACCESS_KEY_ID=ваш_идентификатор_ключа
AWS_SECRET_ACCESS_KEY=ваш_секретный_ключ
AWS_DEFAULT_REGION=ru-central1
S3_ENDPOINT_URL=https://storage.yandexcloud.net
S3_BUCKET=mlops26-course-bucket
S3_KEY=prepared/listings.csv
```

Если `.env.example` не входит в набор сдаваемых файлов, создайте `.env` вручную с этими же именами переменных. Значения `AWS_ACCESS_KEY_ID` и `AWS_SECRET_ACCESS_KEY` получаются от владельца хранилища. В этом рабочем проекте они перенесены в локальный `.env` из выданного файла `secretkeys.py`; исходный файл сохранён. Ноутбук читает настройки из `.env` и больше не импортирует `secretkeys.py`.

Заданные заранее переменные окружения имеют приоритет над `.env`. Ключи, `.env`, `secretkeys.py`, CSV и `.venv/` исключены через `.gitignore`. Не размещайте настоящие ключи в ноутбуке, README, `.env.example` или GitHub. Файлы, которые уже отслеживаются Git, необходимо отдельно убрать из индекса.

## Работа ноутбука

Откройте `01_read_data.ipynb` в VS Code и выполните ячейки сверху вниз:

1. `read_s3_csv(bucket, key)` получает CSV через `s3.get_object` и возвращает `pandas.DataFrame`.
2. `read_data(bucket, key, local_path=None)` сначала обращается к S3. При ошибке доступа или сети выводит сообщение и читает локальную копию, если путь передан.

Столбец `listing_id` читается как строка. Ошибки разбора CSV не скрываются. Если запасной путь не указан, передаётся исходная ошибка S3; если локальный файл отсутствует, возникает `FileNotFoundError`.

## Проверка

1. Убедитесь, что в `.env` указаны bucket `mlops26-course-bucket` и key `prepared/listings.csv`.
2. Выберите ядро проекта и выполните ноутбук сверху вниз. Первое прямое обращение к S3 требует работающего подключения.
3. Проверьте первые строки, размеры и названия столбцов. Убедитесь, что создана локальная копия `data/listings.csv`.
4. Вызов с правильным ключом должен вернуть таблицу из S3. Вызов с суффиксом `.missing` должен сообщить о переходе к локальному файлу и вернуть его содержимое.

Если S3 недоступен с самого начала, положите тот же CSV в `data/listings.csv` и выполните ячейки импортов и определений функций, затем вызовите `read_data` с локальным путём. Отдельную ячейку прямого чтения из S3 при этом можно пропустить.

## Дальнейшие этапы

В материалах преподавателя Wine используется как учебный пример. Для этого проекта сохраняется набор Inside Airbnb: столбцы включают `listing_id`, `room_type`, `property_type` и числовую `price`. Задачу и целевую переменную следует зафиксировать перед обучением модели.

На этапе обучения сначала нужно разделить данные, затем настроить преобразования только на обучающей выборке и объединить их с моделью в `sklearn Pipeline`. Модель и предобработка сохраняются вместе; проверка и инференс используют загруженный Pipeline без повторного обучения. Docker-файлы для следующих этапов пока не реализованы.
